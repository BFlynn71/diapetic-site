# diapetic.com

The DiaPetic website: Home, How to use, FAQ & support, Privacy policy. Plain HTML and CSS on GitHub Pages (custom domain in `CNAME`).

## Editing

The pages are generated by `_build/build.py` (GitHub Pages ignores folders that start with `_`, so it isn't published).
Edit the text in that file, then run `python3 _build/build.py` from the repository root and commit the changed HTML.

Keep **How to use** (`help.html`) and **FAQ** (`faq.html`) in step with the app: whenever a feature is added or changed in the app, update these pages in the same session.
